# Task: M0 — engineering baseline + frozen core contracts

## Goal

Establish a reliable Backend foundation: runnable services, database migrations, frozen core
contracts, Event infrastructure, Task/Goal/CurrentState/Memory/Plan APIs, permissions/audit, object
storage, worker, tests and CI.

## Inputs

- `AGENTS.md`, `TECH_STACK_AND_WORKPLAN.md`, `GOALS.md`
- M0 delivery checklist from the project brief

## Outputs

- Runnable FastAPI + PostgreSQL + Redis/Arq + S3-compatible stack via Docker Compose
- Alembic initial migration for 13 tables
- Pydantic contracts + OpenAPI (`openapi.json`)
- Unit + integration tests; Ruff/Pyright/CI green
- `DEVELOPMENT.md` status + `M0_HANDOFF.md`

## In scope

Backend, data models, migrations, Event/Task/Goal/CurrentState/Memory/Plan APIs, permissions, audit,
object storage abstraction, worker, tests, CI, OpenAPI, adapter contract for OneTHU.

## Out of scope

LLM planner/Agent runtime, Chat/proactive behavior, real campus adapters, PDF/PPT/audio parsing,
pgvector/retrieval/citations, notifications, offline sync, complex authz policy, credential storage.

## Acceptance criteria

- `docker compose up` starts the stack; API serves `/health` and `/openapi.json`.
- `alembic upgrade head` works from zero and `alembic check` shows no drift.
- Every core contract has DB model + schema + API + tests.
- Event dedupe, user isolation and permission/audit behavior are tested.
- Full Study + Time loop integration test passes.
- Ruff, Pyright and pytest pass in CI.

## Status

Completed for M0 scope. Remaining verification items tracked in `DEVELOPMENT.md` (full-suite run,
`-m storage` against s3mock, Arq worker against Redis).
