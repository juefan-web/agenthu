## 3. B 自域核点（协调人派工六项）

1. **逐字段可渲染性**：A §4 DTO 集对客户端全部可渲染；`?` 语义（必有
   可 null）与 B §1 的 `.nullable()` 必填键纪律一一对应；A-r2 未新增
   客户端字段（§9-4 是输入收窄），无重镜像遗漏。strip 风险面：A §4
   「strict enum、拒绝未知字段」与客户端「恒发新字段同批进 Zod」
   sequencing 互补。
2. **防枚举五条 × B capability 规则拼接**（协调人指定焦点）：A-r2 §4
   （≥128-bit、统一 404、双限流 429+Retry-After、digest 第二因子、
   无时延 oracle、能力不进日志）与 B 规则（Authorization 头不在 URL、
   不进日志/遥测/剪贴板自动复制、Stronghold 独立槽）**零缝**——B 侧
   并集更宽（剪贴板/遥测两维），并补客户端侧不给枚举面：receipt 视图
   统一「回执不可用」文案（本轮已入 B 稿 §2）。
3. **manual retry 收紧 × receipt 只读自洽**（指定焦点）：账号删除后
   owner 无法业务认证 → 无手动重试、状态走 receipt 轮询、能力只读——
   三者在 A §2/§4 与 B §2（本轮同步后）文本闭合；source/memory 的
   FAILED 重试 = expected_version 409 模式，与 M4 confirm 同构，客户端
   行为路径无分叉。
4. **本地清理状态机**：A 侧无客户端状态机主张（本机清理全归 B 稿），
   无冲突；verified 判据已按 A 建议定义为可复跑命令输出。
5. **owner 命名空间相容性**：A §7 同步代际（X-Data-Generation 例）与
   B owner_key + data_generation 独立保存相容；无主队列禁自动归当前
   账号、重基逐项校验，双方文本一致；A §7「不得仅客户端改代际头绕过」
   与 B「客户端不是权限判定者」同向。
